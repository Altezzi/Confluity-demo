# Confluity Desktop

Tauri 2 + React/TypeScript client. Local-first workspace covering CRM, Support, Projects, Docs, Operations, Finance, Portal preview, AI drafts with approval, and Settings sync/integrations.

```bash
# from repo root
npm install
npm run desktop:dev
```

See the root [README](../../README.md) for the Phase 0–10 demo walkthrough. Hosted PostgreSQL/SSO connectors are still later.
